# Does idle KV add work to an active request?

The relevant llama.cpp changes pass active row indices to flash attention and restrict key-pool scoring to current sequences. They are pinned in consolidation baac624 at upstream 952b2a4 and 84ba70f. In M40-LLM Phase 4 48c6333, buffered decoding defaults to serialized admission under the generation mutex. With batched decode requested, dense and preferred direct FP16-K/Q4-V can use leased slots; unsupported compressed configurations retain serial admission. Streaming and buffered scheduling have distinct entry points. A batch of one uses a single-sequence consumer. Each layer maps the request's logical sequence to a physical slot before forwarding.

Trace src/server.rs scheduler_can_use_batched_attention and process_scheduler_batch_tick, src/infer/kv.rs kv_physical_slot_for_layer_sequence, src/infer/forward.rs forward batch dispatch and src/decode_batch.rs DecodeBatchPlan::from_requests. Completed/cancelled requests do not enter the active sequence and length arrays. The batched CUDA wrapper copies the two *active* arrays to the CPU to compute shared memory capacity. Its launch has query_heads by batch_size CTAs. Each CTA selects seq_ids[batch_idx], and scores old blocks only up to seq_lens[batch_idx], with a slot-specific base address. These synchronous metadata copies may cost host time and scale with active batch size. They do not scan every reserved sequence. Reservation and attention traffic therefore require separate measurements.

Freeze a head128 16-query/2-KV-head operator control with 2,048 active tokens, 1,024 recent, 32 per block and top8. Keep two physical slots with 4,096-token capacity; compare 0, 512, 2,048 and 4,096 retained tokens in the second slot while always addressing only slot zero. Include a one-slot baseline and a two-active-sequence positive control. Compare full output bits at fixed active work including the first row of the positive control, actual logical shape/selected capacity and both event and elapsed intervals. Warm all arms and alternate order for five rounds. Record external host, GPU telemetry and raw observations. An isolated operator cannot qualify HTTP latency or physical DRAM traffic. Close the row-index proposal if the runtime already restricts work to active slots and the measurements show no reproducible additional work. Investigate a new consumer only if the current loop demonstrably visits idle KV.
