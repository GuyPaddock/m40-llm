# C2 batch invariance and rollback

The Phase 4 packed verifier already compares committed states at 2, 4 and 8 rows, tests rejection at each position and clears rejected cache words. Existing direct-four tests reject aliases and unsupported shapes. Extend cases where stale state could affect a second verification transaction. Test disjoint model owners with alternating work, cancellation followed by retry, forced partial commit, all-accepted and rejection paths. Compare the subsequent multi-token continuation and both layers' cache extents to independent serial sessions. Require exact greedy IDs and exact unchanged-prefix bits. Existing alternate-arithmetic tolerance is 1e-3 + 2e-5 * abs(reference) for logits and 2e-3 for decoded FP16 cache values. Require equal vector lengths before computing discrepancies. Direct arithmetic uses the historical bitwise contract. Report near-tied decisions with the observed margin, including controlled equal/near-equal outputs.

Include all-zero/padded activations, zero Q8 scales and tail dimensions in the real C1 operator or applicable existing controls. Freeze independent/candidate row counts, shapes and buffer guards before kernel timing. A mismatch, stale position, illegal access, nonfinite output or unexplained near-tie blocks C1 promotion. Hardware support and actual execution are reported per cuBLAS mode. Reference studies: ggml-org/llama.cpp #32081, #32045, #32566 pinned at baac624 on the consolidation branch. They motivate regressions; no upstream backend is a Maxwell reference.
